# ATLAS 1939

제2차 세계대전을 전선·정치·사회·경제·기술·민간인 경험·전후 질서까지 연결해서 읽는 한국어 디지털 백과사전입니다.

## 현재 구현 범위

- 24개 심층 문서와 문서별 참고문헌
- 13개 주요 전투·작전 심층 도감
- 전투별 배경, 지휘관·전력, 작전 구상, 시간순 전개, 승패 요인, 전후 영향
- 야사 신뢰도(`기록 확인`·`해석 논쟁`·`후대의 전설`)와 관련 서적 관점
- 1937–1945 핵심 연표
- 8개 주제 영역 필터
- 제목·요약·태그 통합 검색
- 연관 문서 자동 추천
- 모바일·태블릿·데스크톱 반응형 UI
- 정적 문서 생성(SSG), 메타데이터, 사이트맵, robots.txt
- Vercel 무설정 배포 호환

## 기술 스택

- Next.js 16 App Router
- React 19 + TypeScript
- Tailwind CSS 4 + 프로젝트 전용 CSS 디자인 시스템
- Lucide React 아이콘

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증

```bash
npm run lint
npm run build
```

## 콘텐츠 추가

일반 백과사전 데이터는 `src/data/wiki.ts`, 심층 전투 도감은 `src/data/battles.ts`에 있습니다. 각 타입에 맞춰 항목을 추가하면 목록, 상세 페이지, 관련 문서와 사이트맵에 자동 반영됩니다.

- `/explore` 검색·분류 결과
- `/article/[slug]` 정적 문서 페이지
- 관련 문서 추천
- `sitemap.xml`

## Vercel 배포

1. 이 저장소를 Vercel에 Import합니다.
2. Framework Preset은 `Next.js`가 자동 선택됩니다.
3. 별도 환경변수나 빌드 설정 없이 Deploy를 누릅니다.

CLI를 사용할 경우:

```bash
npx vercel
```

프로덕션 도메인이 정해지면 `src/app/layout.tsx`, `src/app/sitemap.ts`, `src/app/robots.ts`의 기본 URL을 실제 도메인으로 교체하세요.

## 편집 원칙

- 사실, 해석, 논쟁을 구분합니다.
- 사망자 수처럼 불확실한 값은 범위와 산출 한계를 함께 설명합니다.
- 유럽 중심 서술을 넘어 중국, 식민지 조선, 동남아시아와 점령지 경험을 포함합니다.
- 학살·성폭력·강제동원을 선정적으로 재현하지 않습니다.
- 단일한 ‘모든 정보’를 주장하기보다 검토일과 참고문헌을 갖춘 확장 가능한 지식 구조를 지향합니다.
